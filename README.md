# Password Generator

My third programming project, developed in July 2026. This is a desktop application built with Python and Tkinter that generates secure random passwords and allows copying them directly to the clipboard.

## Features

- Custom GUI: Styled with a dark theme inspired by VS Code interface guidelines.
- Secure Generation: Combines uppercase/lowercase letters and digits to create 12-character random passwords[cite: 4].
- Clipboard Integration: One-click copying functionality to save generated passwords to the system clipboard[cite: 4].
- User Experience: Includes custom button hover states and centered entry alignment for clean presentation[cite: 4].

## How to use

1. Make sure you have Python installed.
2. Clone this repository or download the password_generator.py file[cite: 4].
3. Run the script: python password_generator.py
